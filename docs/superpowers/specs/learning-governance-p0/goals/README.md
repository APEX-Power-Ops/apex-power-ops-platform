# Learning Goal Records

Status: DESIGN EXAMPLES - NOT A MACHINE REGISTRY

This directory demonstrates the tracked records that the later goal registry
will replace or validate. A file here does not authorize execution by itself.

Each goal must have:

- an operator-authorized charter;
- exact role assignments;
- immutable evidence and decision references;
- a current checkpoint;
- a bounded output root; and
- a closeout or explicit hold.

Use the templates under `../templates/`. The primary executor may act only on a
goal whose state and explicit GO admit the requested work.
